# HH-Parser

CLI-утилита для автоматизации поиска работы на hh.ru с AI-анализом вакансий через Groq API.

## Возможности

- **Трехэтапная воронка обработки** для оптимизации расхода токенов
- Парсинг вакансий с hh.ru с автоматической генерацией фильтров на основе резюме
- PreFilter — предварительная фильтрация по заголовкам до парсинга полной страницы
- Автоматическая фильтрация по стоп-словам (технологии, которые вам не подходят)
- Быстрый скоринг вакансий (batch-запрос, 1-10 баллов)
- Глубокий AI-анализ топовых вакансий на соответствие вашему резюме
- Генерация персонализированных сопроводительных писем
- Создание отчётов по вакансиям и компаниям
- Параллельная обработка вакансий (3-5 одновременно)
- Встроенный rate limiter для защиты от превышения лимитов API

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:

```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

4. Получите бесплатный API ключ Groq на https://console.groq.com/keys и добавьте его в `.env`:

```
GROQ_API_KEY=your_api_key_here
```

5. Отредактируйте файл `resume.md` с вашими данными

## Использование

### Рекомендуемый способ: Полный цикл с воронкой

```bash
npm run full -- --limit 25
```

Это запустит все 3 этапа:
1. **Парсинг** 25 вакансий с автофильтрами на основе резюме
2. **Быстрый скоринг** всех вакансий
3. **Глубокий анализ** топ-10 вакансий + генерация писем

### Только парсинг вакансий (этап 1)

```bash
npm run parse -- --query "frontend vue" --limit 20
```

### Только воронка (этапы 2-3 для уже спарсенных вакансий)

```bash
npm run funnel
```

### Полный цикл с настройками

```bash
npm run full -- --limit 30 --min-score 6 --top-n 15 --parallel 5
```

### Переобработка резюме

Если вы обновили файл `resume.md`:

```bash
npm run refresh-resume
```

## Параметры командной строки

### Режимы работы
- `--mode` - режим работы (по умолчанию: `full`):
  - `parse` - только парсинг (этап 1)
  - `funnel` - только воронка (этапы 2-3)
  - `analyze` - старый режим без воронки
  - `full` - полный цикл с воронкой (все 3 этапа)
  - `refresh-resume` - переобработка резюме
  - `refresh-filters` - переобработка фильтров

### Парсинг
- `--query` - поисковый запрос для hh.ru (используется если `--no-filters`)
- `--limit` - количество вакансий для парсинга (по умолчанию: 20)
- `--no-filters` - не использовать автогенерацию фильтров

### Воронка (этапы 2-3)
- `--min-score` - минимальный скор для глубокого анализа (1-10, по умолчанию: 5)
- `--top-n` - количество топовых вакансий для глубокого анализа (по умолчанию: 10)
- `--parallel` - количество одновременных запросов к LLM (по умолчанию: 3)

## Как это работает

### Трехэтапная воронка обработки

#### Этап 1: Парсинг с умными фильтрами
- AI генерирует фильтры на основе вашего резюме
- PreFilter отсеивает неподходящие вакансии по заголовку (до загрузки полной страницы)
- Парсинг N вакансий с hh.ru
- Сохранение данных в JSON-файлы

#### Этап 2: Быстрый скоринг
- **Batch-запрос:** Все вакансии обрабатываются одним запросом к AI
- **Быстрая оценка:** Каждая вакансия получает скор 1-10
- **Отсев:** Вакансии с низким скором отбрасываются

#### Этап 3: Глубокий анализ
- Сортировка по скору и отбор топ-N вакансий
- Параллельная обработка (3-5 одновременно)
- Детальный анализ соответствия резюме (0-100 баллов)
- Генерация персонализированных сопроводительных писем
- Создание отчётов

## Конфигурация

Основные настройки в `src/config.js`:

```javascript
{
  parsing: {
    defaultLimit: 20,           // Лимит вакансий по умолчанию
    filterAdvertised: true      // Фильтрация рекламных вакансий
  },
  delays: {
    min: 3000,                  // Мин. задержка между запросами (мс)
    max: 10000                  // Макс. задержка
  },
  funnel: {
    quickScore: {
      minScore: 5               // Мин. скор для глубокого анализа
    },
    deepAnalysis: {
      topN: 10,                 // Кол-во вакансий для глубокого анализа
      parallelRequests: 3       // Параллельные запросы
    }
  }
}
```

## Защита от блокировки

- Рандомные задержки 3-10 секунд между запросами к hh.ru
- Реалистичный User-Agent
- При получении капчи/403 — автоматическая остановка

## Лимиты Groq API (Free Tier)

| Модель | Запросов/мин | Токенов/мин | Токенов/день |
|--------|--------------|-------------|--------------|
| llama-3.1-8b-instant | 30 | 6,000 | 500,000 |
| llama-3.3-70b-versatile | 30 | 12,000 | 100,000 |

Встроенный rate limiter автоматически замедляет запросы при приближении к лимитам.
