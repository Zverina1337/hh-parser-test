## 🎯 Краткосрочные планы (v0.2-0.3)

### ✅ Система статусов вакансий (TODO-like)

**Проблема:** Сейчас есть только технические статусы (`parsed`, `analyzed`), но нет возможности отметить:
- На какие вакансии я уже откликнулся
- Какие вакансии мне интересны
- Какие отклонены мной вручную
- На какие получен ответ от работодателя

**Решение:** Расширенная система статусов + CLI команды для управления.

#### Новые статусы

```javascript
// Технические статусы (автоматические)
"parsed"          // Спарсена
"quick_scored"    // Оценена, низкий скор
"ready_for_deep"  // Готова к глубокому анализу
"analyzed"        // Полностью проанализирована
"error"           // Ошибка обработки

// Пользовательские статусы (ручные)
"starred"         // ⭐ Избранная
"applied"         // 📤 Откликнулся
"response"        // 📬 Получен ответ
"interview"       // 🎙️ Назначено собеседование
"rejected"        // ❌ Отклонена мной
"declined"        // 👎 Отклонили меня
"offer"           // 🎉 Получен оффер
"archived"        // 📁 Архив
```

#### Структура данных

```json
{
  "id": "123456",
  "status": "analyzed",
  "userStatus": "applied",
  "userNotes": "Отправил отклик 05.02.2025, жду ответа",
  "appliedAt": "2025-02-05T10:30:00Z",
  "responseAt": null,
  "interviewAt": null
}
```

#### CLI команды

```bash
# Просмотр вакансий по статусу
npm run list -- --user-status applied

# Изменение статуса вакансии
npm run status -- --id 123456 --set applied --note "Откликнулся через hh"

# Добавление в избранное
npm run star -- --id 123456

# Архивирование вакансии
npm run archive -- --id 123456

# Просмотр статистики
npm run stats

# Интерактивный режим (выбор из списка)
npm run manage
```

#### Отчёты с фильтрацией

```bash
# Показать только вакансии, на которые я откликнулся
npm run report -- --filter applied

# Показать вакансии, ожидающие моего решения
npm run report -- --filter analyzed --exclude applied,rejected,archived
```

### 🔄 Обновление вакансий (Refresh)

**Проблема:** Вакансии могут быть закрыты или обновлены работодателем.

**Решение:**

```bash
# Проверить актуальность вакансий
npm run refresh -- --status applied,starred

# Проверить конкретную вакансию
npm run refresh -- --id 123456
```

**Логика:**
- Запрос к hh.ru
- Если вакансия удалена → статус `archived`
- Если изменилось описание → уведомление пользователя
- Обновление данных в `data/vacancies/{id}.json`

### 📧 Уведомления о новых вакансиях

**Проблема:** Нужно регулярно запускать парсер вручную.

**Решение:** Cron-режим (или systemd timer на Linux).

```bash
# Запуск в фоне с проверкой каждые N часов
npm run watch -- --interval 6h

# Уведомление только о новых топовых вакансиях
npm run watch -- --min-score 8 --notify
```

**Уведомления:**
- Desktop notification (Windows: `node-notifier`)
- Telegram bot (опционально)
- Email (опционально)

### 🔍 Поиск по проанализированным вакансиям

**Проблема:** Нет возможности быстро найти вакансию среди проанализированных.

**Решение:**

```bash
# Поиск по ключевым словам
npm run search -- "GraphQL"

# Поиск по компании
npm run search -- --company "Яндекс"

# Поиск по зарплате
npm run search -- --salary ">200000"

# Комбинированный поиск
npm run search -- "React" --company "Яндекс" --score ">8"
```

**Вывод:**

## 🚀 Среднесрочные планы (v0.4-0.6)

### 🏢 Исследование компаний (улучшение)

**Текущая проблема:** Модуль `researcher.js` отключён из-за:
- Timeout при большом количестве запросов к DuckDuckGo
- Низкое качество данных (только сниппеты)

**Новый подход:** Парсинг конкретных источников

#### Источники данных

1. **dreamjob.ru** — отзывы сотрудников
   - Рейтинг компании
   - Плюсы/минусы работы
   - Уровень зарплат

2. **habr.com/career** — вакансии IT-компаний
   - Описание компании
   - Технологический стек
   - Проекты компании

3. **vc.ru** — новости о компаниях
   - Раунды инвестиций
   - Новости о продуктах
   - Репутация

4. **hh.ru/employer/** — страница работодателя
   - Все вакансии компании
   - Описание компании
   - Количество сотрудников

#### Структура данных

```json
{
  "slug": "yandex",
  "name": "Яндекс",
  "rating": 4.2,
  "reviews": {
    "total": 1247,
    "pros": ["Высокие зарплаты", "Интересные задачи"],
    "cons": ["Бюрократия", "Много переработок"]
  },
  "techStack": ["Python", "C++", "Go", "React"],
  "funding": "IPO",
  "employeesCount": 10000,
  "vacanciesCount": 234
}
```

#### CLI команды

```bash
# Исследовать компанию
npm run research -- --company "Яндекс"

# Исследовать все компании из топовых вакансий
npm run research -- --auto

# Обновить данные о компаниях
npm run research -- --refresh
```

### 📊 Веб-интерфейс (простой)

**Проблема:** CLI не всем удобен, хочется визуально смотреть вакансии.

**Решение:** Простой локальный веб-сервер.

```bash
# Запуск веб-интерфейса
npm run web -- --port 3000
```

**Функции:**
- Просмотр вакансий в виде карточек
- Фильтрация по статусам
- Изменение статуса (drag & drop)
- Просмотр сопроводительных писем
- Копирование письма в буфер обмена
- Сравнение вакансий (side-by-side)

**Технологии:**
- Express.js (бэкенд)
- Vanilla JS или Alpine.js (фронтенд)
- Tailwind CSS (стили)
- Без сборки (нативные ESM)

### 🔗 Интеграция с Telegram Bot

**Проблема:** Хочется получать уведомления и управлять вакансиями из телефона.

**Решение:** Простой Telegram Bot.

**Команды:**
- `/start` — регистрация
- `/today` — новые вакансии за сегодня
- `/top` — топ-5 вакансий
- `/apply 123456` — отметить как "откликнулся"
- `/letter 123456` — получить сопроводительное письмо
- `/stats` — статистика

**Уведомления:**
- Новые вакансии с высоким скором (≥8)
- Обновления по откликам
- Напоминания о собеседованиях

## 🌟 Долгосрочные планы (v1.0+)

### 🎯 A/B тестирование откликов

**Идея:** Генерировать несколько вариантов сопроводительных писем и отслеживать, какие работают лучше.

**Метрики:**
- Процент ответов
- Процент приглашений на собеседования
- Скорость ответа

**Обучение:**
- Анализ успешных откликов
- Улучшение промптов для генерации писем
- Персонализация стиля писем

---

### 🧠 Предсказание вероятности отклика

**Идея:** ML-модель для предсказания вероятности положительного ответа.

**Признаки:**
- Скор вакансии
- Рейтинг компании
- Зарплата
- Удалённость
- Совпадение стека
- История откликов

**Вывод:**
```
Вероятность отклика: 72%
Рекомендуется откликнуться: ДА
```

### 📈 Аналитика рынка труда

**Идея:** Накопление данных о вакансиях для анализа трендов.

**Метрики:**
- Средняя зарплата по стеку
- Популярные технологии
- Рост/падение спроса на навыки
- Топ работодателей

**Отчёты:**
```markdown
# Аналитика рынка: Fullstack разработчики (Январь 2025)

## Средняя зарплата: 180 000 руб.
- Junior: 80-120k
- Middle: 150-220k
- Senior: 250-350k

## Популярные технологии:
1. React (78% вакансий)

## Тренды:
↗️ Растёт спрос: Next.js (+12%), TypeScript (+8%)
```

### 🔄 Автоматические отклики (с осторожностью)

**Идея:** Автоматически откликаться на топовые вакансии.

**Ограничения:**
- Только с явного разрешения пользователя
- Только на вакансии со скором ≥9
- Ручная проверка сопроводительного письма перед отправкой
- Лимит откликов в день (например, 3-5)

**Безопасность:**
- Dry-run режим (показать, что будет отправлено)
- Подтверждение каждого отклика
- Логирование всех действий
